# Muhammad Hammad — Project 5 Portfolio

Professional React portfolio showcasing only Projects 1–4.

- Real links to all four live projects and their GitHub repositories
- Responsive design
- Dark/light mode saved in localStorage
- Smooth navigation
- Skills and project roadmap
- Interactive contact form
- GitHub Pages-ready Vite configuration
